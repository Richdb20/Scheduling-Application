Scheduling Application for WGU’s C195 Software Development Program

This is a scheduling application that works with a SQL Database populated with Customer and Appointment Tables. The application is used to create new Customers and Appointments, modify existing Customers and Appointment records, and uses reports to view Customer and Appointment data from the database.

Application Instructions for use

* Login Screen: Input username and password from the database, (e.g. user: test, password: test).
* Main Screen: From this screen, you can view your Customers Table, and your Appointment tables. You can filter appointments by all, weekly, or monthly. You can add a new Customer, or appointment, modify, or delete the select customer/appointment.
* Update Customer Screen: Used to modify the existing customers.
* Update Appointments Screen: Used to modify the existing appointments.
* Reports Screen: Used to view reports, such as the number of appointments by type, per month. View Appointments by contact, or view contact information such as ID, Name, and email.

Additional Report used: I created a table that displays a selected contacts ID, Name, and Email, since nothing in the application had a requirement to display a contacts email, I felt this would be useful.
MySQL Connector Driver Information: mysql-connector-java-8.0.26
